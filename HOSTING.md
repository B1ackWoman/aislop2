# Размещение ROUNDISH 1.15

Для мультиплеера используйте VPS или хостинг с постоянно работающим Node.js и WebSocket. Сервер и сайт находятся в этой поставке. Публичный PeerJS больше не нужен. Выбирайте сервер, доступный из сетей обоих игроков, например VPS в российском дата-центре.

## Проверить у себя

Распакуйте архив, откройте терминал в папке `roundish`. Нужен Node.js 22.12+ или 24.

```sh
npm ci
npm run build
npm start
```

Откройте `http://localhost:3000`. На другом компьютере в той же локальной сети откройте `http://IP-ПЕРВОГО-КОМПЬЮТЕРА:3000`. Разрешите входящий TCP-порт 3000 в брандмауэре для локальной сети. В игре поле «Адрес сервера игры» оставьте пустым: соединение будет с сервером открытого сайта.

Один создаёт комнату, другой вводит код. Бот доступен и без сервера.

## VPS с HTTPS

1. Установите Docker и Docker Compose на VPS. Это обычный Docker-хостинг, не статический хостинг.
2. Направьте A-запись домена на публичный IP VPS. Если задана AAAA-запись, IPv6 тоже должен вести на этот сервер.
3. Откройте TCP-порты 80 и 443. Порт 3000 наружу открывать не нужно.
4. Загрузите папку `roundish` на VPS. Скопируйте `.env.example` в `.env`, замените `game.example.com` своим доменом.
5. В этой папке выполните:

```sh
docker compose up -d --build
```

Caddy получает HTTPS-сертификат и передаёт HTTP/WebSocket-запросы в контейнер игры. Оба игрока открывают `https://ваш-домен`. Для кириллического домена в `.env` используйте его ASCII/Punycode-представление из панели регистратора; в браузере можно вводить кириллицу.

Проверка сервера: `https://ваш-домен/health` должна вернуть `{"ok":true,"version":"1.15"}`. Логи: `docker compose logs --tail=100`.

## Если сайт на отдельном статическом хостинге

HTML можно разместить отдельно, но сервер комнат всё равно должен быть запущен. В окне «С другом» оба игрока указывают одинаковый адрес, например `https://game.example.com`. На HTTPS-странице нельзя подключаться к HTTP-серверу: нужен HTTPS/WSS.

Если комнаты не подключаются, проверьте `/health`, одинаковый адрес у обоих игроков и проксирование `/rooms` с поддержкой WebSocket на вашем хостинге. Обычный `python -m http.server` и загрузка одного HTML на Netlify не запускают сервер комнат.

Node.js сервер и игровой протокол проверяются настоящими локальными WebSocket-соединениями. Docker/Caddy-конфигурация предоставлена для размещения; контейнерная публикация на вашем VPS здесь не выполнялась.

Песни для победных эмоций подключаются через `public/emotes/tracks.json`: см. [EMOTE-SONGS.md](EMOTE-SONGS.md).
